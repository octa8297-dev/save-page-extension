# Полное копирование страницы

Расширение для Firefox и Chrome, которое целиком сохраняет длинные страницы с виртуальным скроллингом — claude.ai, Gemini, ChatGPT и другие. Обычное «Сохранить как» берёт только видимую часть; расширение прокручивает страницу до конца, собирает весь текст и картинки и отдаёт результат в нужном формате.

## Возможности

- **Автопрокрутка** длинных SPA-страниц с настраиваемой скоростью (Тщательно / Обычный / Быстро)
- **Захват всего содержимого**, а не только того, что сейчас на экране
- **Умный захват чатов** (Claude, Gemini) с сохранением ролей — видно, где реплика пользователя, а где ответ ассистента
- **Форматы сохранения:**
  - Markdown (`.md`) — с форматированием: жирный, курсив, код, таблицы, ссылки, списки
  - Word (`.doc`) — с картинками
  - HTML — с картинками; при желании они вшиваются прямо в файл
  - TXT (простой текст)
  - PDF — с картинками
- **Картинки встают на свои места** — каждая привязана к тексту, который стоял перед ней на странице; иконки, аватары и кнопки отсекаются
- **Копирование в буфер** — только текст или с форматированием
- **Фильтрация интерфейсного мусора** — кнопки, счётчики и статусы в файл не попадают
- **Защита от побочных кликов** — расширение не активирует вложения и ссылки на странице

### PDF в разных браузерах

| Кнопка              | Firefox | Chromium (Chrome, Edge, Opera, Brave) |
|---------------------|:-------:|:-------------------------------------:|
| PDF сразу в файл    | ✅ `tabs.saveAsPDF()` | — кнопка не показывается |
| PDF через печать    | ✅      | ✅ открывается диалог печати → «Сохранить в PDF» |

`tabs.saveAsPDF()` — нестандартное API, которого в Chromium нет. Поэтому в сборке для Chromium фонового скрипта нет вовсе, а PDF сохраняется через диалог печати браузера.

## Установка

### Firefox
Из [Firefox Add-ons](https://addons.mozilla.org/) — ссылка появится после публикации.

Для разработки:
1. Открыть `about:debugging` → «Этот Firefox»
2. «Загрузить временное дополнение…» → выбрать `manifest.json`

Временная установка сбрасывается при перезапуске браузера.

### Chrome, Edge, Opera, Brave
Из Chrome Web Store — ссылка появится после публикации.

Для разработки:
1. Собрать пакеты: `./build.sh`
2. Распаковать `dist/page-saver-chrome-<версия>.zip` в отдельную папку
3. Открыть `chrome://extensions/`, включить «Режим разработчика»
4. «Загрузить распакованное расширение» → выбрать эту папку

## Использование

1. Открыть страницу, которую нужно сохранить
2. Нажать на иконку расширения
3. Настроить:
   - **Прокрутить до конца** — оставить включённым для длинных страниц
   - **Встроить картинки** — вшить картинки в сам файл, чтобы `.doc`/`.html` открывался без интернета. Картинки со сторонних доменов, которые страница не отдаёт скриптам (CORS), расширение скачивает через своё окно — у него этого ограничения нет
   - **Скорость прокрутки** — «Тщательно» надёжнее на тяжёлых страницах, «Быстро» экономит время
4. Нажать нужную кнопку сохранения или копирования

## Поддерживаемые платформы

| Платформа  | Захват текста | Роли сообщений | Особенности                                       |
|------------|:-------------:|:--------------:|---------------------------------------------------|
| claude.ai  | ✅            | ✅             | Собирает все сегменты ответа между инструментами  |
| Gemini     | ✅            | ✅             | Разворачивает свёрнутые блоки перед захватом      |
| ChatGPT    | ✅            | —              | Базовый захват текста                             |
| Любой сайт | ✅            | —              | Универсальный режим                               |

Роли сообщений и полноценное форматирование (`**жирный**`, таблицы, блоки кода) доступны в `.md`: он собирается из HTML-структуры страницы отдельным треком. Остальные форматы строятся из текста.

Если на каком-то сайте `.md` выходит пустым или неполным, нажмите **🔬 Диагностика структуры** — расширение сохранит дамп DOM, по которому можно поправить селекторы.

## Требования

- Firefox 142+ либо Chrome / Edge / Opera / Brave 102+
- Manifest V3

## Разрешения

- `activeTab` — доступ к текущей вкладке в момент, когда вы нажали на иконку расширения
- `scripting` — запуск скрипта захвата на этой вкладке
- `tabs` (только Firefox) — сохранение PDF через `tabs.saveAsPDF()`
- `clipboardWrite` — копирование в буфер после долгой прокрутки: к её концу браузер уже не считает действие пользовательским и без этого разрешения отказывает
- `<all_urls>` — нужен, чтобы при включённой галочке «Встроить картинки» скачать изображения со сторонних доменов и вшить их в файл

Расширение **не отправляет никаких данных наружу** — весь разбор страницы происходит локально, в вашем браузере. Единственные сетевые запросы — загрузка картинок с той же страницы, и только если вы включили встраивание.

## Структура проекта

```
manifest.json         — манифест для Firefox (с фоновым скриптом)
manifest-chrome.json  — манифест для Chromium (без фонового скрипта)
popup.html, popup.js  — интерфейс расширения
content.js            — движок: прокрутка, захват, конвертация
background.js         — прямое сохранение PDF, только для Firefox
print.js              — вызывает диалог печати на странице «PDF через печать»
icon.svg, icon-*.png  — иконки
build.sh              — сборка пакетов в dist/
```

Один и тот же код работает в обоих браузерах: `popup.js` и `content.js` берут либо `browser.*`, либо `chrome.*` — смотря что доступно. Различаются только манифесты, и `build.sh` подставляет нужный.

## Сборка

```bash
./build.sh
```

Создаёт `dist/page-saver-firefox-<версия>.zip` и `dist/page-saver-chrome-<версия>.zip`.
